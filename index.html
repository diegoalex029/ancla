Conectar objetos físicos (NFC)

Cada hábito se puede activar tocando un objeto real con el celular, usando un tag NFC programado.

  1. Consigue tags NFC tipo NTAG213 (búscalos en Mercado Libre o Amazon, son económicos).
  2. Instala la app gratuita NFC Tools (Android o iOS).
  3. Publica esta app (botón compartir/publicar del artifact) y copia su enlace.
  4. En NFC Tools → Escribir → Añadir un registro → URL/URI. Pega tu enlace y agrégale el parámetro del hábito que quieres, por ejemplo:

Acerca el celular al tag para grabarlo, luego pega el tag al objeto (frasco, dado, tapete de meditación, etc). La próxima vez que lo toques con el celular, el hábito se marca solo.
